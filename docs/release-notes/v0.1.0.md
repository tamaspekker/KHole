The first public release of KHole: a fast, keyboard-driven triage tool for DJs on macOS.
Open a folder of new promos, listen to each track for a few seconds, and send it to a
destination folder, keep it, or trash it with a single key.

**Requirements:** macOS 13 or later on Apple Silicon (M1 or newer).

### Install

1. Download `KHole-0.1.0-arm64.dmg` below, open it and drag KHole into Applications.
2. **First launch:** KHole is not signed with a paid Apple Developer ID, so macOS will refuse
   to open it at first. Click **Done**, then open **System Settings › Privacy & Security**,
   scroll down and click **Open Anyway**. You only need to do this once.

### What's in 0.1.0

- One key per decision: `1`–`0` to a destination, `Enter` keep, `Backspace` Trash, auto-next.
- Waveform preview with a configurable start point, seeking, tempo fader with keylock.
- BPM and key from tags, or from the bundled Essentia analyzer in the background.
- Folder tree, track search, destination bar with drag & drop, `M` to move anywhere.
- Edit Title, Artist and the file name in place.
- Sessions you can continue later, summary at the end, *Undo session*.
- Remappable shortcuts (`?`), light and dark mode.
- File safety: nothing is ever deleted permanently (macOS Trash), nothing is overwritten,
  everything can be undone.
